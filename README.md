# Naimo 🚀

Умная платформа поиска работы с AI-агрегацией вакансий, анализом соответствия и отслеживанием актуальности данных.

## 🎯 Возможности

- **AI-матчинг** — оценка соответствия вакансии вашему профилю через локальную нейросеть (Ollama)
- **Агрегация данных** — сбор вакансий из публичных API (HH.ru, RemoteOK, Dev.to)
- **Умная фильтрация** — удалёнка, зарплата, свежесть публикаций
- **Контроль актуальности** — автоматическое отслеживание изменений и архивация неактуальных вакансий
- **Генератор cover letter** — персонализированные сопроводительные письма на основе AI

## 🛠 Технологический стек

- **Frontend**: Next.js 15 (App Router), React, TypeScript
- **Стилизация**: Модульный SCSS, Radix UI (headless-компоненты)
- **База данных**: SQLite (через Drizzle ORM)
- **AI**: Ollama (локальная модель llama3.1:8b)
- **Сборка**: Turbopack

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки (Turbopack)
npm run dev -- --turbo
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 📁 Структура проекта

```
src/
├── app/              # Next.js App Router (страницы, layout)
├── components/       # UI-компоненты (модульный SCSS)
├── lib/              # Утилиты, API-клиенты, база данных

```

## 🤖 AI-интеграция

Проект использует локальную нейросеть через Ollama для:

- Оценки соответствия вакансии резюме (scoring)
- Нормализации данных из разных API
- Генерации сопроводительных писем

Убедитесь, что Ollama запущен локально:

```bash
ollama serve
```
